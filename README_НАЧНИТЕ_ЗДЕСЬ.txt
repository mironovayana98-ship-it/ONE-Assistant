ONE v0.4 — Gemini (тестовая версия, 9 ноября 2026)

ВАЖНО: этот архив содержит серверную функцию netlify/functions/one-gemini.mjs.
Обычная загрузка папки/ZIP через Netlify Drop не гарантирует публикацию функции.
НАДЁЖНЫЙ ПУТЬ: подключить репозиторий GitHub к существующему сайту Netlify и настроить автоматические сборки.

1) Создайте репозиторий GitHub и загрузите содержимое ЭТОЙ папки, включая netlify/functions и netlify.toml.
2) В Netlify откройте СУЩЕСТВУЮЩИЙ проект inquisitive-meerkat-9315fa → Project configuration → Build & deploy → Continuous deployment → Link repository.
3) Выберите репозиторий и deploy. Проверяйте список Functions в Netlify: one-gemini должна появиться.
4) В Netlify → Project configuration → Environment variables создайте:
   GEMINI_API_KEY = секретный API-ключ из https://aistudio.google.com/app/apikey
   ONE_FAMILY_CODE = длинный случайный код (не менее 8 символов), который вы сообщите маме отдельно от ссылки.
   ONE_GEMINI_MODEL = gemini-2.5-flash-lite (необязательно)
   Для ключа и кода выберите доступность для Functions.
5) Перезапустите deploy (Deploys → Trigger deploy), чтобы переменные вступили в силу.
6) Проверяйте сайт только на тестовых, НЕ личных данных. Введите семейный код в ONE и спросите, как проверить память телефона.

НИКОГДА не добавляйте Gemini ключ в index.html, app.js, one-gemini.js или GitHub.
Не присылайте его в чат и не делайте скриншот с открытым ключом.

СВОЙСТВА ПРОТОТИПА:
- Можно задавать свободные вопросы на русском, украинском, французском и английском.
- Можно прикладывать JPG/PNG/WebP, картинки уменьшаются на телефоне.
- Ответы озвучиваются системным синтезатором, голосовой ввод зависит от браузера.
- Сохранены офлайн-инструкции и тестовые напоминания (надёжны только при открытом сайте).
- ИИ не управляет экраном, не видит чужие приложения автоматически и не проверяет банковские счета.
- Сервер применяет семейный код и приблизительный лимит 30 запросов/час на инстанс; это НЕ глобальный лимит, не полноценная защита от злоупотреблений. Для публичного релиза нужны внешние квоты/лимиты, защита от перебора и журнал ошибок без персональных данных.
- Бесплатные запросы Google могут использоваться для улучшения моделей. Не загружайте личные, медицинские, банковские документы, пароли, коды или фото детей.
- Доступность и лимиты бесплатного Gemini API зависят от региона, аккаунта и действующих тарифов.

Если в ONE появится «Gemini ещё не подключён» — проверьте, опубликована ли функция и переменная GEMINI_API_KEY.
Если 404 при запросе функции — скорее всего, ZIP загружен через Drop без сборки функций: требуется Git deploy.
